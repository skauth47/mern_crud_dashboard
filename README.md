# MERN User Management Dashboard

A full-stack CRUD application built using MongoDB, Express, React, and Node.js.

## Tech Stack

- React
- Node.js
- Express
- MongoDB

## Features

- Create users
- Read users
- Update users
- Delete users

## Installation

### Backend

cd mern_backend
npm install
npm run dev

### Frontend

cd mern_frontend
npm install
npm run dev
